# 🚦 AI-Based Traffic Sign Recognition Using CNN

A software-based traffic sign recognition application using a Convolutional Neural Network (CNN).

## Features
- Upload a traffic sign image
- CNN-based classification
- Displays predicted sign and confidence
- Shows meaning and a safety alert
- Built with Python and Streamlit

## Dataset
The project uses the GTSRB (German Traffic Sign Recognition Benchmark) dataset with 43 traffic-sign classes.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Model
Place the trained model file named `traffic_sign_cnn.keras` in the same folder as `app.py`.
